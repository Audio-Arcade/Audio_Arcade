1. Ajoutez vos musiques via le bouton "Fichiers" puis "Explorez", ou si vous n'avez pas de musique cliquez sur "Télécharger des musiques" (import direct depuis YouTube).

2. Si un CD audio est inséré, Audio_Arcade le détecte automatiquement et vous propose de l'importer directement dans votre playlist (clic droit sur le lecteur > "Importer le CD audio avec Audio_Arcade" également disponible).

3. Contrôlez votre musique via les boutons de contrôle, ou grâce aux raccourcis clavier :
   • Espace : Lecture / Pause
   • Flèche gauche : Piste précédente
   • Flèche droite : Piste suivante
   • R : Relancer la playlist depuis le début
   • Touches multimédia du clavier (Play/Pause, Suivant, Précédent, Stop) également prises en charge.

4. Activez le mode "Lecture en boucle" ou "Lecture aléatoire" (disponible à partir de 10 musiques dans la playlist) via les boutons dédiés.

5. Sauvegardez vos musiques en playlist avec le bouton "Sauvegarder la playlist" (formats .aarcade ou .txt).

6. Ouvrez votre playlist avec le bouton "Charger une playlist".

7. Ajoutez plus de musique avec le bouton "Ajouter plus de musique".

8. Sauvegardez la musique en cours avec le bouton "Enregistrer la musique".

9. Utilisez ArcadeShare pour diffuser votre musique en temps réel à d'autres personnes :
   • Cliquez sur "Cast" pour créer une room de diffusion permanente et partager le code généré.
   • Ou utilisez "Code de lecture" pour rejoindre la room de quelqu'un d'autre avec un pseudo et un code.
   • L'hôte peut suivre en direct le nombre d'invités connectés.

10. Réduisez la fenêtre pour afficher le mini-lecteur flottant, pratique pour garder le contrôle de la musique sans revenir sur la fenêtre principale.

11. Le titre de la musique en cours de lecture s'affiche également dans votre statut Discord (Rich Presence), avec la possibilité de voir si vous êtes en train de diffuser (cast) ou en écoute partagée.

12. Les touches médias de votre clavier ou de votre casque (lecture, pause, piste suivante/précédente) fonctionnent aussi en dehors de la fenêtre de l'application.
